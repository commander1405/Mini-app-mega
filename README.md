## انتشار در GitHub Pages
1. یک مخزن عمومی جدید بساز؛ مثلاً `mega-bot-website`.
2. فایل `index.html` و این `README.md` را مستقیماً در ریشه مخزن قرار بده.
3. وارد **Settings → Pages** شو.
4. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کن.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.
6. پس از پایان انتشار، لینک GitHub Pages در همان بخش نمایش داده می‌شود.
