یک ربات، چندین ابزار کاربردی

این بخش بر اساس فهرست قابلیت‌های فعلی MEGA BOT نوشته شده است؛ اجرای برخی عملیات مدیریتی به مجوزهای لازم در گروه و پشتیبانی API بله بستگی دارد.

⛨

مدیریت و امنیت گروه

قفل لینک، ضداسپم، پیام تکراری، منشن انبوه، فوروارد، ضدتبلیغ، ضد فحش، Flood و قفل انواع رسانه؛ همراه با اخطار و مجازات خودکار.

⌘

مدیریت اعضا

سکوت و رفع سکوت، بن و آنبن، کیک، اخطار، حذف اخطارها و پاک‌کردن پیام‌ها با گزارش نتیجه عملیات.

⚙

تنظیمات گروه

پنل تنظیمات، قفل زمان‌بندی‌شده با پشتیبانی از عبور از نیمه‌شب و منطقه زمانی تهران، قوانین و پین پیام.

✉

نجوا

ارسال نجوا با ریپلای، نمایش پیام فقط برای گیرنده، امکان حذف پیام فرستنده در صورت داشتن مجوز و محدودیت نرخ ارسال.

✦

یادگیری کلمات

یادگیری تکی و گروهی، فهرست و حذف عبارت‌ها، ریست حافظه و ذخیره جداگانه برای هر گروه یا گفت‌وگوی خصوصی.

♧

سرگرمی و بازی

چالش، فکت، حقیقت، جرئت و بازی‌های گروهی مثل دوز، شیر یا خط و هرکی تک بیاره.

↗

قیمت‌های زنده

دریافت قیمت دلار، ارز، بیت‌کوین و طلا از سرویس api.priceto.day؛ دسترس‌پذیری وابسته به سرویس منبع است.

▧

ساخت گیف

ساخت گیف با ریپلای یا متن دلخواه، نمایش متن سفید و Bold داخل کادر و تلاش برای فشرده‌سازی حجم خروجی.

♙

خوشامد و بدرقه

پیام خودکار ورود و خروج، روشن/خاموش‌کردن، متن سفارشی، پاسخ متنوع و منشن با شناسه کاربر.

◉

آمار و اطلاعات

آمار سراسری ربات، آمار ورود و خروج و انواع پیام گروه، پیگیری محدودیت شخصی و فهرست اعضای ویژه.

♧

گفت‌وگوی اجتماعی

پاسخ به عبارت‌های روزمره، پیام‌های فقط‌ایموجی و عبارت‌های «مگا» یا «بات»، همراه با معرفی سازنده.

▤

پنل مالک و ادمین

پنل‌های /admin و /owner برای آمار، جست‌وجو، محدودیت‌ها، تیم، تبلیغ، حمایت مالی، پیام همگانی و مدیریت ادمین‌ها.

امکانات تکمیلی

ابزارهای کاربردی‌تر

چند قابلیت دیگر که در کنار ابزارهای مدیریتی در دسترس هستند.

♡

حمایت مالی

ثبت درخواست حمایت، تأیید یا رد توسط مالک، اعلام به کاربران، تنظیم کارت و متن معرفی و اصلاح دستی مجموع آمار حمایت.

◌

محدودیت عضویت

تنظیم بازه زمانی برای ورود آزاد، پنجره محدودیت و انتخاب اخطار یا اخراج طبق تنظیمات گروه.

▣

پیام همگانی و تبلیغ

ارسال پیام همگانی از پنل مالک با گزارش موفق/ناموفق و امکان تنظیم دکمه تبلیغ زیر پیام‌های معمولی.

توجه: حذف پیام، بن، قفل‌های گروه و برخی اقدامات دیگر ممکن است به ادمین‌بودن ربات و مجوزهای کافی نیاز داشته باشند. اگر API بله عملیاتی را پشتیبانی نکند یا دسترسی لازم وجود نداشته باشد، آن عملیات ممکن است انجام نشود.

آیا این سایت به دیتابیس وصل است؟

خیر. این یک وب‌سایت استاتیک است و هیچ دیتابیس یا بک‌اندی ندارد.

آیا سایت روی GitHub Pages اجرا می‌شود؟

بله؛ فایل‌ها با HTML و CSS و JavaScript ساخته شده‌اند و به فرایند build یا Node.js نیاز ندارند.

آیا این صفحه خودش ربات را کنترل می‌کند؟

خیر. این سایت فقط صفحه معرفی است. کنترل واقعی ربات به امکانات خود ربات و زیرساخت آن وابسته است.
